这个网站是使用 GitHub Pages + Jekyll + Chirpy 搭建的第一篇博客。

浑浑噩噩的度过了大一和大二，马上就要去到了基地，再过两年就面临毕业 or 考研。还有一周就要开始期末，周六就有迫在眉睫的六级考试，然而此时却并没有任何激情去复习六级或者备考；相反我却浪费了一整个晚上来搭建一个似乎没有什么意义的网站，这篇博客即是我这一整个晚上的心血。

早已没有了高中时的热血沸腾，也许我再也不会因为达到某个目的而彻夜不眠了，毕竟我确实难以沉下心来学我不感兴趣的东西，或者说，我不知道对未来有什么帮助的东西。

从大一到大二，我亲眼目睹 AI 技术的突飞猛进。我记得在刚进入大一时，AI 离我们的生活很远，而且令人感到遥不可及，有时候其给出的答案还不如去网上直接搜索别人的博客。那会老师要求完成的约瑟夫问题，所有的大模型给出的都是链表解法；我自己是手搓的数组，对比于链表那确实是高下立见了。不过，步入大学不久的我们连内存申请都会担心内存泄漏问题，又怎么可能真的搓出一条链表？

我感到嗤之以鼻，同时对未来抱有期待甚至是幻想。任何事情努力就会有结果，学习 Clang 后学 C++，再学 java 和 python ，学 Web 三件套再去学 vue 和 React（大一时期的我天真的像是一个没见过世面的土猪，数的过来多少语言就幻想要学会多少语言），再然后......

再然后就是 GPT-4.4 的横空出世。彼时刚学会如何科学上网，注册了一个谷歌邮箱后立刻便登上了Open AI。我开始使用 AI 来辅助我敲代码，使用 AI 来帮我写一些结课论文。还真别说，AI 能做的事情还真不少，我发现我能写的东西 AI 也写得出来。

不过那会也只是充满了好奇心，我仍然是兢兢业业的小码农，使用 GPT 也只是想尝尝鲜，科学上网的工具很快就被我抛之脑后。AI 再次进入我的眼帘已然是大一下学期的暑假小学期了。

在这段时间之前的学业压力不小，相比于怎么使用 AI，更多时间还是被放在了数据结构、高等数学和大学物理上。我能够手搓链表，手搓 DFS 和 BFS，甚至能自己用 C 语言写一个雷霆战机，作为大作业提交给程序设计老师。

等我再一次想到了 AI，则是一个棘手的黑白棋项目。minimax 算法与 alpha - beta 剪枝理论实现很简单，但若想在众多代码中与对手达成平局还真的不容易。我于是第一次接触到 Cursor，在 trae 、codex、claude code 不存在的那个时代 Cursor 宛如高达一般，自动分析各个文件，自动修改各个代码。

那是我第一次被 AI 震惊到。当我熬夜去学习如何手搓迪杰斯特拉算法时，AI 能够在半分钟内给出更为精辟的代码；我所追求达到的高度似乎在一瞬间被压成了奇点，这么多没日没夜的时间都可以经由 AI 得到归一，手搓代码存在的唯一的意义似乎已经简单成为了考试硬性要求的一项基本技能。

当然在擂台赛我们小组发现原来其他小组也开始使用了 AI，大家都是开着高达来打的擂台赛。

不过也正是在这个夏天，感觉 AI 暴风般的席卷进入我们的生活。豆包和 Gemini 的出现让人们逐步了解 vibe coding，程序员与其他人的区别也似乎越来越小。也是，大家都有属于自己的创意与巧思，能够用语言来完成的事情又何必为难自己去从 0 开始来完成一个网页。

人工智能这个名词，逐渐从各行各业的嘴里迸发出来，就连我的小学的外甥也知道了人工智能。除了使用 GPT，我也尝试了使用 Gemini 和 Claude（一秒就被封了，现在还没解除），代码能力也真的是一绝。

说实话，按照道理来说 AI 这么厉害会对我们的学习带来莫大的帮助，但是这里有一个值得深思的问题，这些事情 AI 都能做我为什么要去学。我一度感到绝望，不清楚学习计算机的意义是什么，开发、算法、运维、测试、安全，有几个行业会在 AI 的发展之下能够存活下来。大一的幻想随时间的流逝逐渐变得苍白与飘渺，获取知识的速度还不及 AI 迭代的速度。

这也是未来的趋势吧，现在所有人都在唱衰计算机，大家也互相在开玩笑是下一代土木；曾以为安全会成为我作为程序员的独具特色的标志，在 opus 4.7 发现的漏洞面前我的这个想法也是显得滑稽不堪。

今天下午还在思考以后到底需要往哪方面努力，被 AI 解放的时间如果没有用来学习用来胡思乱想也是挺好的。不太寄希望于软件开发，也就不太有动力来学习python语言啥的。以后的目标是学习嵌入式，既然不想编写软件或者开发算法，盘弄盘弄FPGA或许不失为一种好选择。

仍然不想复习。时候不早了，作为我在 GitHub 上的第一个项目，我的感想差不多也就到此打住；还是尽量做到一直维护我的博客吧，虽然大部分都是 GPT 5.5 的功劳。没有关系，是我生成的就是我的功劳。我现在选择学习的嵌入式，在5年之后希望发现自己选的是正确的道路。
