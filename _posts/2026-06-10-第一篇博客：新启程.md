# 我的第一篇博客

这是我使用 GitHub Pages + Jekyll + Chirpy 搭建的第一篇博客。

我准备用这个博客记录自己的学习过程，包括：

- 计算机课程复习
- C++ 刷题训练
- 嵌入式和单片机学习
- RISC-V / FPGA 项目
- 数据库、操作系统、计组复习
- GitHub 使用和项目整理
- Ubuntu、Docker、VSCode 等工具踩坑

## 为什么想写博客

以前我的学习内容比较零散，很多问题都是临时查、临时问、临时解决。

但是如果不整理，这些经验很快就会忘记。

所以我希望通过博客把学习过程记录下来，一方面方便自己以后复习，另一方面也能慢慢形成自己的项目展示。
